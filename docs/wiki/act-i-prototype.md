## Goal

Reach Quiet Harvest after surviving the Ash Belt deck.

Quiet Harvest is prototype Arrival. Reaching it means success immediately.

## What Act I Must Prove

The prototype is successful only if these are true:

| Test |
|---|
| Players understand the cycle after one round. |
| Every cycle has at least two plausible priorities. |
| Players voluntarily use MOTHER in some games. |
| Waking crew feels tempting before it feels safe. |
| Opening a chamber feels like changing the ship's future, not drawing a random perk. |
| Ration pressure makes population matter without forcing food work every turn. |
| The table state remains readable with one Site, one standing Event, and several chamber tasks. |
| Reaching Quiet Harvest feels like a clean win. |
