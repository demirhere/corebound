# COREBOUND

COREBOUND is a cooperative survival card game about named humans, partial knowledge, and irreversible shortcuts.

Players guide a damaged colony ship from Earth Wreckage toward Arrival. Every cycle asks whether the crew spends people, time, and materials now, or lets MOTHER solve the problem and make the future less human.
